# Portfolio Agung Saeful (React + Vite)

```bash
npm install
npm run dev       # mode pengembangan -> http://localhost:5173
npm run build     # hasil produksi di folder dist/
npm run preview   # cek hasil build
```

- Data proyek, sertifikat, dan **kontak** ada di `src/data.js` (isi objek `CONTACT` agar tombol kontak muncul).
- Gambar ada di `public/img/`. Ganti file dengan nama yang sama untuk memperbarui karya.
- Folder `dist/` bisa langsung di-upload ke Netlify, Vercel, atau GitHub Pages.
